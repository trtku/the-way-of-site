# やってはいけないこと

うっかりやると、サイトが止まったりリンクが切れたりするものだけを並べています。
逆に言えば、**ここに書いていないことは、だいたい元に戻せます。**

---

## 絶対にやらないこと

### 1. シートの1行目（英語の列名）を書き換える／消す
プログラムはこの行を目印に読んでいます。
触ると、その日から反映が止まります。
（念のため、編集しようとすると警告が出るようにしてあります）

### 2. 列の順番を入れ替える／列を削除する
同じ理由です。**列を増やすのは右端なら大丈夫**ですが、
サイトには出ません（出すにはコードの変更が必要です）。

### 3. 一度公開した `slug` を変える
URLが変わり、**SNSやnoteに貼ったリンクが全部切れます。**
書き間違えたときは、公開前であれば直してかまいません。

### 4. シートの名前を変える
`issues` `exhibitions` `reading` `notes` `news` の5つは、名前で読んでいます。

### 5. スプレッドシートの共有設定を「制限付き」に戻す
「リンクを知っている全員が閲覧可」であることが、反映の前提です。
※ 編集できるのは招待した人だけなので、閲覧可にしても勝手に書き換えられることはありません。

---

## やってもいいこと（よくある不安）

- **行を途中に挿入する** … OK。並び順は日付や `order` で決まります
- **使わない行を空欄のまま残す** … OK。空の行は無視されます
- **`公開する` のチェックを外す** … OK。下書きとして残しておけます
- **色を付ける・メモ列を右端に足す** … OK。見た目には影響しません
- **写真を入れ替える** … OK。同じファイル名で上書きすれば差し替わります

---

## 困ったときの順番

1. ［サイト］→［反映の状況を見る］で、赤い × の回を開く
2. メッセージに「何シートの何行目か」が出ている
3. 直して、もう一度［サイトに反映する］
4. それでも直らないときは、開発した人に **その×のページのURL** を送る
