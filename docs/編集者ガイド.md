# 編集者ガイド

サイトの中身は、すべて **スプレッドシート `THE WAY OF → CMS`** で決まります。
コードを触る必要はありません。

---

## 1. いちばん短い手順

1. スプレッドシートを開く
2. 直したい行を直す（または新しい行を足す）
3. いちばん右の **`公開する`** にチェックを入れる
4. 上のメニュー **［サイト］→［サイトに反映する］** を押す
5. 3〜5分待つ → サイトが新しくなる

**チェックを外すと、その行はサイトから消えます。** 行ごと消す必要はありません。

---

## 2. シートの読み方

どのシートも、上2行は固定です。

| 行 | 中身 | さわる？ |
|---|---|---|
| 1行目 | 英語の列名（プログラムが読む） | **さわらない** |
| 2行目 | 日本語の説明（人が読む） | さわらない |
| 3行目以降 | データ | ここを編集する |

---

## 3. シートごとの役割

### `issues` — 月刊の号
毎月1行ずつ足します。**ここを1行足すと、トップページの顔が入れ替わります。**

- `year_month` … `2026-11` のように **YYYY-MM**
- `title` … その月のテーマ（例: 都市の隙間をあるく）
- `recommend_1` 〜 `recommend_6` … 「今月おすすめの過ごし方」。空欄の分は出ません
- `feature_slug` … トップで大きく扱う展示の `slug`（`exhibitions` シートの値と一致させる）
- `photo_1` 〜 `photo_4` … 左側に並ぶ写真の**ファイル名**

### `exhibitions` — 展示・プロジェクト
1展示 = 1行。詳細ページが自動で1枚できます。

- `slug` … URLになる記号。**半角の英小文字・数字・ハイフンのみ**。
  `/exhibitions/nora-1-0/` の `nora-1-0` の部分。
  **一度公開したら変えないでください**（リンクが切れます）
- `status` … `ongoing`（開催中）／`upcoming`（開催予定）／`archive`（終了）。
  会期が終わったら `archive` に変えます
- `start` / `end` … 会期。会期バーとカレンダー追加（.ics）に使われます
- `cover` … カバー写真のファイル名
- `works_count` … 作品数（数字だけ。無ければ空欄）
- `map_url` … Googleマップの共有リンク（任意）

### `reading` — 読み物（note など）
- `url` … `https://` から始まるリンク
- `thumb` … サムネイル画像のファイル名
- `date` … 公開日。新しい順に5件がトップに出ます

### `notes` — 今月の書き手
- `issue` … どの号か（`2026-10` のように）
- `order` … 並び順（1, 2, 3 …）

### `news` — お知らせ
新しい順に3件がトップに出ます。

---

## 4. 写真の入れ方

1. Driveの **`01_画像入稿`** フォルダに、写真をそのまま入れる
2. シートのセルには **ファイル名だけ** を書く（例: `nora-cover.jpg`）
   - ❌ URLを貼る必要はありません
   - ❌ 共有設定をいじる必要もありません
3. ［サイトに反映する］を押す

**ファイル名は半角英数字で**。日本語のファイル名でも動きますが、
あとで探しにくくなるので `nora-cover.jpg` のような形を勧めます。

写真が見つからないときは、灰色の仮置き（斜線の箱）が出ます。
**サイトが壊れることはありません。** あとから写真を入れて、もう一度反映すれば直ります。

写真は自動で軽くされます（WebPに変換、表示サイズに合わせて複数書き出し）。
**元の写真はそのまま入れてください。縮小は不要です。**

---

## 5. うまく反映されないとき

［サイト］→［反映の状況を見る］を開くと、赤い × が付いた回に理由が出ます。
よくあるのは次の3つです。

| 出るメッセージ | 直し方 |
|---|---|
| `slug は半角の英小文字・数字・ハイフンのみです` | 大文字・スペース・日本語が入っています |
| `exhibitions シートに slug「○○」が見つかりません` | `issues` の `feature_slug` のつづり違い |
| `年月は YYYY-MM 形式で入力してください` | `2026/10` ではなく `2026-10` |

**入力に問題があるときは、サイトは更新されません**（壊れた状態では公開されない作りです）。
直してもう一度押せば大丈夫です。
